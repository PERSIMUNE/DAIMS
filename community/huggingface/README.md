# DAIMS

DAIMS brings a data standardization checklist, dataset documentation, and a data dictionary into one framework for AI and medical research. Explore its tools and templates before starting your analysis.

- [Open the DAIMS app ↗](https://daims-app.streamlit.app/)
- [Documentation and examples](https://github.com/PERSIMUNE/DAIMS/blob/main/DAIMS_DatasetName_DDMMYYYY.md)
- [GitHub](https://github.com/PERSIMUNE/DAIMS)
- [Methods paper](https://arxiv.org/abs/2501.14094)

Developed by Ramtin Zargari Marandi, PhD. Full project credits are available in the linked repository and paper.
